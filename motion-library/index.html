Motion library

49 animations + 1 component · one set of tokens · everything built on them

What this is

Every animation the Marketing Hub uses — 49 of them, across entrances, exits, attention, text and ambient loops — in one place, built on one set of tokens. The catalogue covers the motion ideas you find in Animate.css and Animista; none of their CSS is used here, because a keyframe written against their constants would not respect our duration scale. Copy the snippet, load the two stylesheets, done — there is no build step, no framework and no third-party animation library. If a motion needs a duration or an easing no token covers, the token file gets a new entry; nothing is hardcoded to make one animation work.

How to use it

Load in this order — tokens/motion-tokens.css, then base/base-animations.css, then any entry CSS — and put the class on the element. Stagger a list by setting --ml-index per item. To hold an animation until it scrolls into view, add ml-paused and remove it with an IntersectionObserver. To slow one down, add ml-slow (1.5×), ml-slower (2×) or ml-slowest (3×) — they set --ml-scale, which multiplies whatever duration the animation already has, so an entrance, an exit and a loop all slow by the same factor. The property inherits, so putting the class on a wrapper slows everything inside it. To take the whole set somewhere else — another site, a campaign page, a partner — use dist/continia-motion.css: tokens and all 49 animations in one self-contained file, with a README.md beside it. It is generated, so edit base/base-animations.css and run node tools/gen-motion-dist.js rather than editing the bundle.

Every animation honours prefers-reduced-motion. The tokens collapse durations and travel distance to nothing, and the loops switch themselves off — the element still ends in its final state, so nothing disappears for someone who asked for less movement. The Reduced motion switch in the gallery below sets data-motion on the page so you can see both versions without changing your OS setting; it starts on if your system already asks for reduced motion.

Tokens

the single source of truth · tokens/motion-tokens.css

Duration

Picked by purpose, not by feel. Anything past 800ms reads as slow rather than considered.

--motion-duration-instant100ms
--motion-duration-fast150ms
--motion-duration-base250ms
--motion-duration-moderate400ms
--motion-duration-slow600ms
--motion-duration-slower800ms

Easing

Entrances decelerate, exits accelerate. That asymmetry is what makes motion feel physical.

--motion-ease-standard0.2, 0, 0, 1
--motion-ease-out0.16, 1, 0.3, 1
--motion-ease-in0.7, 0, 0.84, 0
--motion-ease-in-out0.65, 0, 0.35, 1
--motion-ease-linearlinear

Stagger & distance

Stagger multiplies by --ml-index. Distance is how far an element travels — never further than 32px.

--motion-stagger-tight30ms
--motion-stagger-base60ms
--motion-stagger-loose100ms
--motion-distance-sm8px
--motion-distance-md16px
--motion-distance-lg32px
Mirrored for JavaScript in tokens/motion-tokens.js, which also exports the nearest GSAP easing names and a prefersReducedMotion() helper that respects the gallery toggle as well as the OS setting. Use the mirror rather than retyping numbers into a script.
